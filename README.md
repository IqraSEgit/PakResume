**PakResume** - ATS-Optimized CV Builder 

PakResume is a lightweight, interactive, and customizable web application designed to build ATS-optimized resumes and CVs quickly. It allows users to edit details using an intuitive control panel or through direct live editing on the resume preview, custom themes, multiple typography options, and export the final document directly as a PDF.



##  Key Features

- **Live Interactive Editing:** Edit your CV using the sidebar form or directly click on text inside the resume canvas to edit in real time (`contenteditable`).
- **Custom Color Themes:** Choose from multiple curated palette accents (Classic Blue, Emerald Green, Indigo, Crimson, Slate, and Amber).
- **10 Google Typography Styles:** Instantly switch between modern sans-serif and classical serif fonts (Inter, Poppins, Montserrat, Roboto, Merriweather, Playfair Display, etc.).
- **Pre-loaded Profile Presets:** Quickly load starter content for Software Graduates, Educators, Sales Professionals, or Virtual Assistants.
- **Dynamic Custom Sections:** Add extra fields dynamically (e.g., Projects, Certifications, Languages, Publications).
- **One-Click PDF Export:** Export your resume cleanly using `html2pdf.js` with integrated print CSS fallbacks to eliminate UI clutter.
